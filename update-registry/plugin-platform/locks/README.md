# Locks Directory

This directory stores resolved install graphs (lock state files) at runtime.

Lock files are generated by the Dependency Manager and contain:

- resolved plugin versions
- resolved dependency versions
- dependency edges with constraint origins
- integrity hashes (SHA-256)
- platform variant selections

Lock files enable:

- reproducible installs
- safe uninstall via reference counting
- diagnostics and traceability

This directory is empty in the repository template and populated at runtime.
